# 职场异变图鉴

一款 90 年代复古像素风的中文职场 MBTI 测试。通过 24 道职业抱负、办公室政治、模糊需求和临时加活等情境题，鉴定玩家会进化成哪一种“公司物种”。

[在线体验](https://career-mbti.qiqi7714.chatgpt.site)

## 功能

- 20 道固定情境题与 4 道自适应平衡题
- 完整映射 16 种 MBTI 公司物种
- 每种人格拥有独立像素角色、诊断文案和四轴结果
- 行为型“工伤勋章”与跨局人格图鉴
- 微信、朋友圈、Instagram、X 和 Messages 分享入口
- 自动生成 4:5 结果海报，支持保存图片与复制分享文案
- 响应式桌面与手机布局
- 进度使用浏览器 `localStorage` 保存在本机

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。MBTI 页面同时可通过 `/` 与 `/mbti.html` 访问。

## 验证与构建

```bash
npm test
npm run build
```

生产文件输出至 `dist/`，可部署到任意静态网站托管服务。

## 技术栈

- React 19
- Vite 7
- Node.js 原生测试运行器

## 说明

测试结果仅用于娱乐，不用于招聘、晋升或职业评估。
