# 职场生存手册

中文职场养成网页游戏。第二版围绕「春山项目」和试用期名额，改为有黑色幽默、人物动机、日常关系与长期后果的十二周群像。

## 启动

```bash
npm install
npm run dev -- --port 5173
```

打开 http://127.0.0.1:5173/ 。这是本机预览，未部署公网。生产构建 `npm run build`，产物在 `dist/`，可由静态网站服务托管。React + Vite，无账号、服务端或运行时 AI 依赖。

## 第二版玩法

- 12 周，每周 3 次养成安排，再经历一场日常关系和一场工作交锋。
- 共 24 场剧情、72 个选择、近 400 句对白与回应（含条件分支，单局不会看见全部）。
- NPC 来回对话、主角心里话、私聊、说话人立绘切换；逐句阅读、快进、回看及逐句存档。
- 午饭选座、奶茶拼单、团建、深夜回复、私聊截图、送礼、匿名互评、私人求助与散伙饭。
- 具体经历改变后续对话和同一选项的代价；11 个可触发的延迟后果，进入指定周与事件时兑现。
- 人物与旧账页面：三人的动机、语言习惯、已解锁私事、亲疏与共同经历。
- 每个选项有对方接话与交易复盘；有时做对事会得罪人，有时讨好会留下未来工作量。
- 能力门槛、工作记录、作品集、关系支持、PIP、精力耗尽与 7 类结局。
- 保留主角头像、三位同事立绘、两处背景、轻音乐、全屏和手机布局。

新版从第一周独立开始，使用 localStorage `workplace-survival-v2`。旧版存档 `workplace-survival-v1` 不覆盖。不跨设备同步；清理浏览器数据会清除存档。音乐默认关闭。

## 文件

- `src/characters.js`：人物设定、已发现的背景与关系记忆。
- `src/daily.js`：12 场日常关系事件。
- `src/work.js`：12 场工作主线事件。
- `src/content.js`：导出与养成行动。
- `src/story-helpers.js`：对白、选项和后果的数据构造函数。
- `src/game.js`：状态机、条件对白、谈判变体、延迟后果、存档与结局。
- `src/ui/`：场景、对白、复盘、人物、手记、安排与结局组件。
- `src/main.jsx`：应用入口、存档和页面组合。
- `src/audio.js`：可选合成环境音乐。
- `src/styles.css`：桌面与手机样式。
- `public/assets/`：已保存在本地的全部美术。
- `docs/narrative-design.md`：剧情方向、关系机制与后续扩写规则。
- `docs/art-direction.md`：第一版视觉规范及原始 Image Gen 提示词。

## 验证

```bash
npm test
npm run build
```

测试覆盖 24 场数据完整性、双事件周结算、逐句存档、条件锁、日常影响工作谈判、延迟后果恰好一次、人物支持、PIP、完整通关与外部机会结局。

使用 Codex 内置浏览器实测一条完整的 24 场路线，以及逐句推进、刷新恢复、角色切换、奶茶事件的延迟回响、旧账解锁和复盘。其他路线有纯函数测试，但未逐条通过 UI 玩遍 72 个选择。数值平衡仍属于原型阶段。
